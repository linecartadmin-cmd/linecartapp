1. Architectural Overview

LineCart 2.0 connects regional sales managers, field sales agents, retail merchants, and delivery drivers over an authenticated REST API served on port 3001.

2. Frontend Architecture

The client is a Single-Page Application (SPA) built with React 18.3 and Vite 6, utilizing TailwindCSS 3.4 for responsive layout styling.

  • Top-Level Error Boundary: ErrorBoundary.jsx wraps all role routes to prevent React unmounting cascades, presenting a recovery card on uncaught exceptions.
  • Authoritative Identity Sync: Validates stored tokens on mount against GET /api/auth/me, ensuring client permissions immediately reflect server-side changes.
  • Laptop View & Mobile Preview: Offers a 12-column responsive layout on laptop screens (lg:grid-cols-12) and an emulated 390×844px smartphone frame with bottom tab navigation in mobile preview mode.
  • Accessible Navigation: Universal icon-only Back button (←) with aria-label="Go back", 42px mobile touch targets, and loop-free history tracking.

3. Backend Architecture

The backend application in server/index.js runs on Node.js (v18+) using Express 4.21.

  • Token Session Registry: Active sessions are registered in an in-memory sessions Map upon login, storing user ID, role, and timestamp. Logging out removes the token immediately.
  • Cryptographic Key Derivation: Passwords use crypto.scryptSync(password, salt, 64) with a 16-byte random salt. Timing-safe comparisons via crypto.timingSafeEqual prevent timing attacks.
  • Role Guards: requireAdmin blocks non-admins; authorizeManagerAccess scopes data to assigned teams; requireDeliveryAgent prevents drivers from modifying unassigned orders.
  • Last Admin Protection: Blocks deleting, demoting, or deactivating the last active Administrator.

4. Map & Routing Subsystems

Diagram 5: Shop Map & Road Route Planning Subsystem
Figure 5.1: Geocoded shop deduplication, radial pin expansion geometry, dual-tile resilience, and OSRM road routing.

Dual-Tile Map Resilience

Leaflet maps in ShopMapScreen.jsx and DeliveryRouteScreen.jsx implement automatic failover. If OpenStreetMap tiles experience network errors or timeouts, the layer dynamically switches to CartoDB Voyager raster tiles without interruption.

Radial Fan-Out Geometry for Co-Located Stores

Shops sharing identical coordinates within ~20m are grouped into a location hub. Pins radiate along a circle of radius r ≈ 0.00018° with dashed leader lines connecting each pin back to the center hub.

OSRM Road Routing Engine

routing.js queries the public OSRM driving engine to sequence stops by road distance. If the service is unreachable, an internal Nearest-Neighbor heuristic based on Haversine distance takes over with a clear disclaimer.
