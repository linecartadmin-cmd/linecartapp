3. Installed Libraries & Usage in Code

  • React (^18.3.1) & React-DOM: Powers the UI across 17 component screens. Manages state via useState, useEffect, useMemo, and useRef.
  • Leaflet (^1.9.4): Powers ShopMapScreen.jsx and DeliveryRouteScreen.jsx. Renders map tiles, polyline routes, custom circular pins, and radial spiderfy expansions.
  • Lucide React (^0.468.0): Provides accessible icons including <ArrowLeft /> for the universal back button, <Truck />, <ShoppingCart />, and <ShieldCheck />.
  • Express (^4.21.1): Hosts 48+ REST API endpoints on port 3001 and serves compiled static assets from client/dist/.
  • Multer (^1.4.5-lts.1): Handles store photo uploads on POST /addcustomer, saving files to server/uploads/.
  • Node.js Native crypto: Computes secure key derivations using crypto.scryptSync(password, salt, 64) with 16-byte random salts.

4. External Web Services Reference

These services are called over the network and are not bundled npm packages:

  • OpenStreetMap Tile Server: https://tile.openstreetmap.org/{z}/{x}/{y}.png — Primary raster tile provider for interactive maps.
  • CartoDB Voyager Tile Server: https://basemaps.cartocdn.com/rastertiles/voyager/{z}/{x}/{y}.png — Automatic zero-downtime fallback layer activated if OSM fails.
  • OSRM Public Routing API: https://router.project-osrm.org/route/v1/driving/{coords} — Public road routing engine for sequencing delivery stops. Includes an internal Nearest-Neighbor heuristic fallback.
  • Google Maps External Link: https://www.google.com/maps/search/?api=1&query={query} — External redirect when drivers tap "Open Maps" for turn-by-turn navigation.

5. Known Architectural Limitations & Legacy APK Compatibility

  • Relational SQL Persistence: All users, sessions, shops, orders, order items, targets, assignments, permissions, and audit logs are persisted in the relational SQL database (001_initial_schema.sql) and survive server restarts.
  • Legacy Decompiled APK Break: The original decompiled linecart.apk sent credentials in URL query strings (@Query("phone") / @Query("password")) and lacked Bearer session tokens. A fresh APK must be built from the updated client via Capacitor (client/capacitor.config.json).
  • Payment Gateway & SMS OTP: Order checkout records payment terms (Credit, Cash) without live banking APIs or SMS OTP dispatch.
  • Public OSRM Rate Limits: The public demo server is subject to throttling; production environments should host a local OSRM Docker instance.

6. Production Deployment Checklist

Complete these steps before deploying to production:

  • [ ] Set NODE_ENV=production: Strictly disables the development shortcut login (admin / admin123).
  • [ ] Configure HTTPS / TLS Termination: Terminate TLS via Nginx, Caddy, or AWS ALB.
  • [ ] Migrate to Relational Database: Connect PostgreSQL or MySQL with ACID transactions for orders and customer tables.
  • [ ] Clustered Session Store: Migrate the in-memory sessions Map to Redis.
  • [ ] Restrict CORS: Replace open CORS with an explicit origin domain whitelist.
  • [ ] Cloud Storage for Uploads: Move storefront photo uploads from local disk to AWS S3 or Google Cloud Storage.
  • [ ] Rotate Default Passwords: Change all default administrator, manager, and driver passwords upon deployment.
