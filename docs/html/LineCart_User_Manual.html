1. System Access & Authentication

LineCart 2.0 is an enterprise field sales automation and delivery operations platform. It can be accessed on laptop or mobile browsers at http://localhost:3001.

Mobile Number Sign-In & Account Security

LineCart enforces strict 10-digit Indian mobile authentication across all four operational tiers:

RoleLogin Identifier FormatLanding PageOperational Scope
Administrator10-digit mobile (6-9xxxxxxxxx)/#admin-dashboardFull organization administration, targets, users, audit logs
Sales Manager10-digit mobile (6-9xxxxxxxxx)/#manager-reportsTeam analytics, quota tracking, assigned orders verification
Field Sales Agent10-digit mobile (6-9xxxxxxxxx)/#overviewStore onboarding, wholesale order booking, daily beat route
Delivery Agent10-digit mobile (6-9xxxxxxxxx)/#deliveryMobile route map, road stop sequencing, status advancement
⚠️ Strict Mobile Validation & POST Body Security
Sign-in accepts only a 10-digit Indian mobile number beginning with 6, 7, 8, or 9 (/^[6-9]\d{9}$/) plus the password in the POST /login JSON body. Usernames, country codes (+91), spaces, and credentials in URL query parameters are rejected (400 Bad Request). Failed logins are rate-limited (429 after 5 attempts in 15 minutes).

First-Time Login & Mandatory Password Change

Newly provisioned accounts or accounts reset by an administrator are marked with mustChangePassword: true. Upon signing in:

  1. The system displays the mandatory Password Change Required modal before granting access to operational features.
  2. Passwords must be at least 8 characters and include uppercase, lowercase, and numeric characters.
  3. Upon submission, the backend re-hashes the password using Node.js native scrypt with a 16-byte random cryptographic salt and redirects to the user's role landing page.

Session Invalidation & Accessible Navigation

  • Session Tokens: Authenticated sessions receive a secure UUID token stored in localStorage, transmitted via the HTTP Authorization: Bearer <token> header.
  • Global Logout: Clicking Sign out in the topbar or mobile bottom navigation immediately terminates the token in the backend session registry and returns to the login screen.
  • Accessible Icon-Only Back Button: Renders a clean arrow (←) without visible text, styled with aria-label="Go back" and an expanded 42×42px touch target on mobile viewports. Includes internal history stack management to prevent infinite redirect loops.

3. Administrator (Admin) Workflows

The Administrator possesses unconstrained organizational oversight and administrative authority across all system entities.

Executive Command Center (/#admin-dashboard)

Provides aggregated financial KPIs: Total System Revenue (₹), Total Orders Booked, Active Stores Count, Active Clusters, and Supervising Managers, plus an audit event stream.

User Management & Safeguards (/#admin-users)

  • Provisioning: Create new user accounts, assign roles (Admin, Sales Manager, Field Agent, Delivery Agent), and set temporary passwords.
  • Editing & Status: Update phone numbers, assigned clusters, or deactivate accounts. Inactive accounts are blocked at login.
  • Last Administrator Protection: Backend rules strictly forbid deleting, demoting, or deactivating the last remaining active Administrator.

Manager-to-Agent Assignments (/#admin-assignments)

Only administrators can assign field sales agents to sales managers. Removing an agent immediately revokes that manager's visibility over the agent's orders and reports.

Sales Quotas & Commodity Targets (/#admin-targets)

Set monthly monetary revenue quotas (₹) and assign item-level commodity targets (Eggs in crates, Onions and Potatoes in kg) for individual field sales agents.

4. Sales Manager Workflows

The Sales Manager oversees an assigned team of Field Sales Agents to drive revenue and ensure market penetration.

Performance Reports & Quota Tracking (/#manager-reports)

Displays real-time revenue targets versus achieved sales, percentage completion gauges, and monetary deficit gaps for the manager's assigned team.

Cluster Shop Map & Spiderfying (/#map)

Visualizes customer store locations. Green pins (✓) represent ordering stores; gray pins (•) represent idle stores. Clicking Fan Out Pins on Map (🕸️) radially expands overlapping stores sharing the same GPS coordinates.

5. Field Sales Agent Workflows

Booking Wholesale Orders (/#order-create)

Field sales agents visit retail stores along their daily route, select items from the wholesale catalog, calculate real-time totals with 5% GST, and submit confirmed orders.

Onboarding New Stores (/#shop-new)

Onboards retail clients by recording owner contact details, capturing GPS coordinates via browser geolocation, and uploading a storefront verification photograph.

6. Delivery Agent Workflows

The Delivery Agent experience (/#delivery) is designed for drivers with large touch targets, high contrast, and bilingual support.

Delivery Route & Stop Sequencing

  • Cluster Selection: Drivers select their operational area (e.g. 📍 Pollachi and Udumalaipet).
  • OSRM Road Routing: Tapping 🚚 Start route sequences stops along real road networks using OSRM, with an internal Nearest-Neighbor heuristic fallback if offline.
  • Co-Located Stops: Co-located shops share a numbered hub pin with radial fan-out markers and a 🏢 Shared Address card badge.
  • Status Progression: Advance orders from In progress → Mark as Picked Up (at hub) → Mark as Delivered (at store).
  • Delivery Issues: Tap Could not deliver to submit a structured reason (Shop Closed, Owner Not Available, Cancelled, Wrong Address).
  • Voice Assistant: Tap 🔊 to have the browser speak stop instructions in English or Tamil.

8. Troubleshooting & Operational FAQ

  • Blank Screen on Load: A top-level React ErrorBoundary catches unexpected exceptions and provides a Reload Application button. Use Ctrl + F5 to clear stale browser caches.
  • Port 3001 In Use: Terminate the blocking process via PowerShell: Get-NetTCPConnection -LocalPort 3001 | Stop-Process -Id {$_.OwningProcess} -Force.
  • Access Denied: Click Sign In Again to refresh the Bearer session token via /api/auth/me.
